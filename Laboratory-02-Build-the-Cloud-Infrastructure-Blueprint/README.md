# Laboratory 02 - Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focused on investigating a cloud-based Linux server and identifying the basic infrastructure components needed to build a cloud environment. The KillerCoda platform was used to inspect a Linux server and document its compute, storage, networking, and operating system resources.

The activity also included researching major cloud providers and designing a simple cloud infrastructure architecture.

## Objectives

- Investigate a Linux cloud server environment.
- Identify compute, storage, networking, and operating system resources.
- Document important server information.
- Compare the infrastructure services of AWS, Microsoft Azure, and Google Cloud.
- Create a simple cloud infrastructure diagram.
- Practice using GitHub and Markdown for technical documentation.
- Understand the basic components of cloud infrastructure.

## Cloud Infrastructure Components

The main cloud infrastructure components identified in this laboratory were:

### Compute

The CPU and RAM provide the processing power and memory required to run applications and system processes.

### Storage

The virtual disk provides storage for the operating system, applications, configuration files, and other data.

### Networking

The IP address and network interface allow the cloud server to communicate with other systems and services.

### Operating System

Ubuntu Linux manages the server resources and provides an environment for running applications and executing commands.
