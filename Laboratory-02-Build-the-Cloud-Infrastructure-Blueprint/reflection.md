
# Mission Reflection

This laboratory activity helped me understand how cloud infrastructure is built and managed. I learned how to inspect a Linux cloud server and identify its compute, storage, networking, and operating system resources.

I also learned the differences between the major cloud providers, including AWS, Microsoft Azure, and Google Cloud. Comparing their services helped me understand that although they use different service names, they provide similar basic cloud infrastructure such as computing, storage, networking, and identity management.

One of the challenges I encountered was using Linux commands to investigate the server and understanding the information shown in the terminal. I also had some difficulty organizing the files in GitHub and uploading the cloud architecture diagram to the correct folder.

Overall, this laboratory improved my skills in Linux, cloud computing, GitHub, Markdown documentation, and cloud infrastructure design. The activity gave me a better understanding of how cloud resources work together to support applications and services.
