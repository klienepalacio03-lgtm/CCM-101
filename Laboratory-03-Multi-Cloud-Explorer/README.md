# Laboratory 03 – Multi-Cloud Explorer

This laboratory activity explores and compares Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Objectives

- Explore major public cloud platforms.
- Identify core cloud services.
- Compare AWS, Azure, and GCP.
- Analyze business requirements.
- Recommend appropriate cloud solutions.
## Checkpoint 7 – Linux Server Investigation

### Linux Server Information

The Linux server was investigated using Linux commands in the KillerCoda Playground.

* **Operating System:** Ubuntu Linux
* **CPU Information:** Collected using the `lscpu` command.
* **Memory:** Collected using the `free -h` command.
* **Disk Space:** Collected using the `df -h` command.

### Cloud Migration Services

If this Linux server were migrated to the cloud, the following services could be used:

| Cloud Provider | Service                | Purpose                                                  |
| -------------- | ---------------------- | -------------------------------------------------------- |
| AWS            | Amazon EC2             | Hosts the Linux server as a virtual machine.             |
| Azure          | Azure Virtual Machines | Provides a virtual machine for running the Linux server. |
| GCP            | Google Compute Engine  | Hosts the Linux server on Google's cloud infrastructure. |

These three services are suitable because they provide virtual machines that can run Linux operating systems. The existing Linux server could be migrated to a cloud-based virtual machine while maintaining control over the operating system and server configuration.
