# GCP Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, artificial intelligence, machine learning, and application development.

## Global Infrastructure

Google Cloud has a global infrastructure consisting of regions and zones. These locations allow organizations to deploy applications and services closer to their users and help support availability, performance, and scalability.

## Cloud Management Console

Google Cloud Console is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources and services. It provides tools that help administrators manage their cloud infrastructure.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that organizations can use to run applications and workloads in the cloud.

### 2. Cloud Storage

Cloud Storage provides object storage for data such as documents, images, videos, backups, and other files.

### 3. Cloud SQL

Cloud SQL is a managed relational database service that allows organizations to run and manage databases in the cloud.

### 4. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

## Three Advantages

1. Google Cloud provides strong capabilities for artificial intelligence and machine learning workloads.
2. Google Cloud provides scalable infrastructure that can support applications with changing workloads.
3. Google Cloud offers strong support for containers and Kubernetes-based applications.

## Typical Enterprise Use Cases

Google Cloud can be used by enterprises for web and application hosting, data analytics, artificial intelligence and machine learning, containerized applications, database management, data storage, and global application deployment.
