# Laboratory 06 - Cloud Deployment Engineer

## Mission Overview

This laboratory focused on deploying an application using Docker and Docker Compose. The activity helped me understand how containers work and how an application container can communicate with a database container.

## Objectives

* Learn the basic use of Docker containers.
* Set up an application and database using containers.
* Use Docker Compose to manage multiple containers.
* Understand how Nextcloud connects to the MySQL database.
* Document the steps and configuration used during the deployment.

## Commands Executed

```bash
docker ps
docker images
docker run
docker compose up -d
docker compose down
docker compose ps
docker compose logs
```

These commands were used to create and manage containers, check available images, start and stop the services, and view the status and logs of the containers.

## Skills Learned

* Managing Docker containers
* Creating and using Docker Compose files
* Understanding two-tier architecture
* Connecting an application to a database
* Using environment variables for configuration
* Basic troubleshooting of containers
* Writing technical documentation
